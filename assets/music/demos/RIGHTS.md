claimed human-authored compositions. No sampled recordings, soundfonts, vocals,
downloaded sound packs, reference songs or artist imitation were used. The renderer
uses mathematical oscillators, envelopes, harmonic sums and seeded noise. Python
and NumPy calculate samples; FFmpeg/libmp3lame encode and measure audio. No cloud
music-generation service was used. Tool use does not itself give those software
projects ownership of these recordings. The renderer's code remains MIT.
